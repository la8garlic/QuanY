# 使用指南

[English](guide.en.md) · [返回首页](../README.md)

## 下载与语言

下载 [QuanY.exe](https://github.com/la8garlic/QuanY/releases/latest/download/QuanY.exe)，双击打开。首次启动按系统语言选择中文或英文。在「设置 → 待命与快捷键 → 界面语言」可随时切换，应用会记住选择。

若要确认下载的文件与发行页一致，可运行下面的命令，与同一版本 `SHA256SUMS.txt` 中的摘要比较。此步骤可选。当前 EXE 尚无 Windows 代码签名。

```powershell
Get-FileHash .\QuanY.exe -Algorithm SHA256
```

## 常用快捷键

| 默认键位 | 操作 |
| --- | --- |
| Ctrl+Alt+M / Ctrl+Alt+J | 全局打开主窗口 / 速记窗 |
| Ctrl+N / Ctrl+O | 新建 / 打开 TXT |
| Ctrl+S / Ctrl+Shift+S | 保存 / 另存为 |
| Ctrl+F / Ctrl+H | 查找 / 替换 |
| Ctrl+K / F8 | 快速切稿 / 专注模式 |
| Ctrl+, | 设置 |

从托盘菜单选择“保存并退出”可以完全关闭应用。全局键注册失败时，打开快捷键设置，用未被占用的组合替换原键；录入过程中按 Esc 取消。

## 稿件保存与恢复

停笔后可等待 0.65、2 或 5 秒自动保存。设置里的默认目录决定新稿首次保存的位置。已有稿件始终关联自己的路径，可以用“另存为”创建另一份。外部程序改动同一文件后，如果泉涌报告写入冲突，请先另存本次编辑，再对照两份文件。导入旧编码文件前，先在其他工具中保留原件并转换为受支持的 UTF-8 或带 BOM 的 UTF-16。

TXT 只包含正文。标题、标签、置顶、修订、独立便笺等数据由 SQLite 稿本维护。备份时先从托盘正常退出，再复制 TXT 所在目录和 `%LOCALAPPDATA%\cn.jianji.writer`。后者沿用早期版本的内部标识。仅复制默认 TXT 目录会遗漏另存到其他位置的文件。

## 升级与排错

正常退出后，用新下载的 QuanY.exe 替换原程序。更换 EXE 所在位置时，先关闭登录启动，移动后再从新位置启动并启用。报告故障请附应用版本、Windows 版本、复现步骤和空白稿件上的表现。截图中的文件名、账户目录和正文应先遮盖。
