# QuanY v1.6.5

[简体中文](v1.6.5.zh-CN.md) · [Download this release](https://github.com/la8garlic/QuanY/releases/tag/v1.6.5)

First public open-source release for Windows x64. The UI is in Simplified Chinese. The version number continues the project's local development history.

- Writing and saving: local TXT files, SQLite recovery copies, configurable folders and autosave delay, external-change detection, UTF-8 and BOM-marked UTF-16.
- Desktop integration: separate customizable global shortcuts for the main window and quick capture, tray residency, sign-in startup and multiple always-on-top memos.
- Library: search titles and bodies, pin and tag manuscripts, switch quickly, compare and restore revisions, view a reference alongside the editor and track writing goals.
- Appearance: light and dark paper themes, type and spacing controls, custom window chrome and a transparent QuanY sidebar mark.

Download the ZIP, compare it with `SHA256SUMS.txt`, then extract it. The archive contains `QuanY.exe`, `LICENSE`, `NOTICE` and `THIRD-PARTY-NOTICES.txt`. WebView2 is required. The executable has no Authenticode signature. Exit older versions using **保存并退出** (Save and quit) before replacing the application. Existing libraries keep using their database.
