# QuanY v1.8.0

[Download QuanY.exe for Windows x64](https://github.com/la8garlic/QuanY/releases/download/v1.8.0/QuanY.exe) · [简体中文](v1.8.0.zh-CN.md)

## Writing long TXT files

- The editor and side-by-side reference pane render visible lines. Chinese IME composition, selections across paragraphs, and undo work across the document.
- F3 navigation and manuscript statistics reuse unchanged text blocks. On the same machine with a 349,630-line sample, median time to find the next match fell from 11.3 ms to 0.6 ms. Opening statistics with all text selected fell from 184.9 ms to 4.5 ms.

## Sidebar file actions

- Right-click a draft and choose **Remove from library…** to hide it. The TXT stays on disk. Reopening it restores its tags and revision history.
- **Permanently delete…** shows the linked path and asks you to type `DELETE` at the second confirmation. Confirming deletes the TXT, local recovery copy, and revision history. Press Esc at either step to cancel.

## Saving and recovery

- Autosave records edits for recovery before writing the TXT. This release fixes the `Invalid column type Null` error that could occur when typing into an empty draft. On upgrade, QuanY updates the database view so previously staged text can be saved.
- Edits preserve mixed line endings, and failed sticky-note saves can be retried.

Run the standalone EXE linked above. To upgrade, choose **Save and quit** from the old version’s tray menu, then replace the executable. If the old version is reporting a save error, first copy the text from the editor into a separate file. [User guide](../guide.en.md)
