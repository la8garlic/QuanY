# 泉涌 v1.8.0

[下载 QuanY.exe（Windows x64）](https://github.com/la8garlic/QuanY/releases/download/v1.8.0/QuanY.exe) · [English](v1.8.0.en.md)

## 长篇 TXT 写作

- 正文和并排参考稿按可见行渲染。编辑长文时仍可使用中文输入法、跨段选择和撤销。
- F3 查找、字数及段落统计复用未改动的文本块。在同机 349,630 行样本中，连续查找下一处的中位耗时从 11.3 毫秒降到 0.6 毫秒，全选后打开统计从 184.9 毫秒降到 4.5 毫秒。

## 侧边栏文件操作

- 右键手稿选择 **移出稿本…** 可隐藏该条目。TXT 留在原处，重新打开后可找回标签和版本历史。
- **永久删除…** 会显示关联文件的路径，并在第二次确认时要求输入“删除”，确认后会删除 TXT、本地恢复稿和版本历史。两步都可以按 Esc 取消。

## 保存与恢复

- 自动保存先记录编辑片段，再写出 TXT。修复了从空白手稿开始输入时可能出现的 `Invalid column type Null` 错误。升级后，泉涌会更新读取视图，使已暂存的文字可以继续保存。
- 编辑含混合换行的文件时保留原有行尾，便笺写入失败后可以重试。

运行上方的单文件 EXE 即可启动。升级时，从旧版托盘菜单选择 **保存并退出**，再替换原来的 EXE。如果旧版正报告保存错误，先将编辑器中的文字复制到另一份文件留存。[使用指南](../guide.zh-CN.md)
