# 泉涌 v1.6.5

[English](v1.6.5.en.md) · [下载此版本](https://github.com/la8garlic/QuanY/releases/tag/v1.6.5)

首个公开开源发行版，面向 Windows x64，界面为简体中文。版本号继承此前本地开发历史。

- 写作与保存：本地 TXT、SQLite 恢复稿、自选目录、可配置停笔自动保存、外部修改冲突提示、UTF-8 与带 BOM 的 UTF-16。
- 桌面待命：主窗口和速记窗各自拥有可配置全局快捷键，支持托盘驻留、登录启动和多张置顶便笺。
- 稿本整理：搜索正文和标题、置顶与标签、快速切稿、版本对照和恢复、并排参考、字数与写作目标。
- 外观：纸色与夜色主题、字体和间距设置、自绘窗口标题栏，侧栏使用透明底泉涌标志。

下载 ZIP 并与同页 `SHA256SUMS.txt` 核对后解压。包内有 `QuanY.exe`、`LICENSE`、`NOTICE` 和 `THIRD-PARTY-NOTICES.txt`。运行需要 WebView2。EXE 未作 Authenticode 签名。旧版本请从托盘“保存并退出”后覆盖程序，已有默认稿本继续使用原数据库。[备份与升级](../guide.zh-CN.md)
