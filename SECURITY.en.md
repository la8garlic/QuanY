# Security policy

[简体中文](SECURITY.md)

The latest public stable version receives security fixes. Confirm the issue against the latest release when practical. Use Issues for ordinary bugs. For possible document disclosure, unauthorized local file access, window permission bypasses or release tampering, use [GitHub private vulnerability reporting](https://github.com/la8garlic/QuanY/security/advisories/new).

Include the affected version, Windows environment, impact and the smallest reproduction using disposable text. Redact real manuscripts, tokens, account paths and personal information. Maintainers use the private report to coordinate confirmation, fixes and disclosure. A GitHub security advisory can identify affected versions and upgrade instructions once a fix is available.

Official binaries are published in this repository's Releases. Compare the SHA-256 digest with the release checksum. If a package appears to have been replaced, retain its URL, download time and digest and report through the same private channel.
